# 任务

根据用户问题和已提供的工具观察，生成研究编排循环的最终回答。

# 证据边界

- 只能使用工具观察中明确出现的事实，不得补充模型记忆、常识或猜测。
- 工具没有返回某字段，不代表数据源中不存在该字段。
- `hasParsedFullText=false` 只表示尚无可检索的解析全文，不等于没有 PDF 或摘要。
- 观察不足时，明确区分“已知信息”“当前缺口”和“下一步所需材料”，不得把未观察到表述成不存在。
- 如果观察互相冲突，分别陈述并保留各自边界，不自行消除分歧。

# 输出要求

- 直接回答用户问题，结构清晰，避免描述内部编排过程。
- 只在确有信息缺口时说明限制。
- 不伪造引用、来源、状态或工具结果。
