# 任务

把输入的科研知识图谱实体类型标签划分为若干语义等价组，并为每组选择一个简洁中文规范标签。

# 输入

标签及出现次数：

{{type_counts}}

# 归并要求

1. 只合并含义相同的类型；上位类、下位类、宽泛类、具体类或仅仅相关的类型不得合并。
2. 大小写、单复数、缩写和跨语言翻译只有在确实语义等价时才能归为一组。
3. `canonical` 必须是与组内所有成员语义等价、且不损失专业粒度的简洁中文分类标签。
4. 组内已有合适中文标签时，必须逐字选用该标签作为 `canonical`。
5. 只有组内完全没有合适中文标签时，才允许为翻译目的生成新的中文 `canonical`。
6. 每个输入标签必须逐字保留，并且在所有 `members` 中出现且只出现一次。
7. 出现次数不能作为合并非等价标签的理由。

# 输出格式

只输出合法 JSON，不得输出 Markdown、解释或额外字段：

```json
{"groups":[{"canonical":"中文类型标签","members":["等价标签1","等价标签2"]}]}
```

# 输出前自检

- 每组成员确实语义等价。
- 每个输入标签有且仅出现一次。
- 每个 canonical 都是简洁中文，且与组内所有成员等价。
- JSON 可直接解析，根字段仅为 `groups`。
