# Task

Translate the Chinese academic search query supplied by the user into concise, search-effective English.

# Requirements

- Preserve the original research intent, technical specificity, quoted phrases, Boolean operators, and recognized abbreviations.
- Prefer standard English academic terminology.
- Do not add concepts, filters, explanations, or search operators that are absent from the input.
- If the input is already English, return a concise normalized version without changing its meaning.

# Output

Return only the translated query as one plain-text line, with no label, Markdown, or explanation.
